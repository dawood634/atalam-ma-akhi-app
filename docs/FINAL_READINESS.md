# عقد التسليم النهائي وحالة الجاهزية

طلب داوود: تسليم نهائي واحد شامل بدل تنزيل نسخ تجريبية متتابعة. أوقفنا إنشاء إصدارات APK عامة تلقائيًا عند كل تعديل. تحتفظ الاختبارات ببناء داخلي للمراجعة؛ لا يعني ذلك إطلاقًا للطلاب.

## النطاق

- صنعاء وعدن معًا.
- السابع والثامن والتاسع الأساسي، والأول والثاني والثالث الثانوي.
- العلمي والأدبي للثاني والثالث الثانوي.
- الناتج ١٦ حالة صف/مسار/فرع يجب توثيق متطلباتها، لا مجرد ١٢ زر صف ومسار.

## تصحيح الفهرس

كانت قيمة المادة «غير محدد» لكل الكتب بسبب استخراج غير صحيح من صفحة الفهرس. صحح التصنيف إلى ٢٨ فئة من عناوين ومعرّفات ١٣٦ كتابًا مرشحًا. هذا تنظيم للفهرس، وليس اعتمادًا لوجود مادة في فرع أو طبعة رسمية. يسجل كل كتاب أساس التصنيف وتلميح الفرع إن كان صريحًا في العنوان، مع بقاء التحقق الرسمي غير معتمد. لا تعني عبارة «مشترك» في فهرس مستقل إثبات تطابق صنعاء وعدن.

الفجوة الأهم: لا توجد عناوين تحمل تصنيف عدن للصفوف ٧–١٠ في الفهرس الحالي. لا يجوز اعتبار كتب صنعاء بديلًا تلقائيًا، ولا اعتبار الفهرس كاملًا. سجل الأعداد والتخصصات: `content/coverage_audit.json`.

## فحص المصادر الرسمية

- إعلان قناة الإدارة العامة للإعلام التربوي عن كتب السابع لعام ٢٠٢٥، مع إحالة إلى قناة الكتب الرسمية: https://t.me/s/YemenEducationC?q=%23الصف_السابع
- رابط الإعلان المحال إليه: https://t.me/Books_Yemen_new/1124?single
- فهرسة إعلان قناة روابط الوزارة تذكر ملف «الرياضيات السابع 1447هـ.pdf»، وهو دليل على أن الاكتفاء بالعينة القديمة غير كافٍ: https://t.me/s/yemeneducation2/41991
- قناة الكتب تصف نطاقها بأنه كتب وزارة صنعاء؛ لا تعتمد لعدن تلقائيًا: https://t.me/Books_Yemen_new
- مرجع وزارة عدن: https://moe-ye.net/كتب-الطالب

تعذر جلب ملفات الكتب من هذه الإحالات مباشرة عبر البحث؛ لم نفحص صفحات الطبعة المشار إليها في الإعلان. لا يساوي نشر إعلان لعام ٢٠٢٥ إثبات التكليف للعام ٢٠٢٦–٢٠٢٧. لا توجد إلى الآن مطابقة مكتملة للطبعات الحالية أو المحذوفات أو توزيع الفروع.

## شرط احتساب المحتوى مكتملًا

لكل حالة صف/مسار/فرع: وثيقة مقررات رسمية، قائمة مواد مؤكدة، ربط كل مادة بكتب محددة الطبعة، ثم قائمة جميع وحداتها ودروسها. لكل درس شرح أصلي وأمثلة وتدريبات بتعليل الإجابات ومراجعة مستقلة موثقة. لا تدخل مسودات الشرح أو روابط الكتب أو الدروس التأسيسية في تغطية المناهج المعتمدة.

## حالة الوظائف

| الوظيفة | الوضع الفعلي |

| اختيار المسار والصف | موجود |

| وحدة رياضيات السابع الأولى | ١٠ مسودات أصلية و٣٠ سؤالًا؛ لم تعتمد كطبعة حالية أو تراجع مستقلًا |

| ربط جهاز الطالب بالمعلم والمزامنة | خادم وعميل أضيفا واختبرا محليًا؛ لا توجد استضافة عامة مفعلة أو تحقق على أجهزة Android فعلية |
| جميع المواد لكل الصفوف والمسارين | غير منجز |

| مراجعة المعلمين والإتاحة واختبارات أجهزة فعلية | غير مكتملة |
| توقيع إنتاجي ونشر نهائي | غير مهيأ؛ التوقيع الحالي تجريبي |

## بوابة النشر

الملف `content/release_readiness.json` يحتفظ بحالات النطاق ومتطلبات القبول، وكل غير المنجز مسجل بحالته الفعلية. `tools/release_gate.py --require-ready` يفشل إذا غابت حالة من النطاق، أو لم توثق المقررات، أو لم تغط دروس مقرر كامل، أو غابت المراجعة والأدلة أو اختبارات الوظائف. لا يكفي تغيير علم باسم «جاهز» إلى true.

الفحص يختبر بنية الأدلة واكتمالها؛ لا يستطيع وحده التصديق على صحة مرجع أو هوية مراجع أو جودة شرح. يلزم فحص الأدلة الفعلية قبل النشر. مسار النشر الإنتاجي والتوقيع لا يزال بحاجة إعداد واعتماد عند جهوزية المحتوى؛ لا يخفي الفحص هذه الفجوة.

## نتيجة الحصر الحالية

- ١٣٦ عنوانًا مرشحًا، مصنفة إلى ٢٨ فئة فهرسية.
- صفر كتاب ثبتت مطابقة طبعته الحالية رسميًا.
- صفر مقرر مكتمل معتمد من المنهج المطلوب.
- ١٦ حالة نطاق مقرراتها الرسمية غير موثقة بالكامل.
- لا يوجد موعد إنجاز موثق؛ لا توجد عملية كتابة تعمل تلقائيًا خارج جلسة العمل.

هذه حالة تنفيذ فعلية، وليست إعلانًا عن اكتمال المشروع.

## تحديث الغرف المتصلة

تفاصيل تنفيذ الخادم والعميل، وحدود التشغيل والاستضافة وحفظ الجلسات: `docs/CLASSROOM_SERVICE.md`. لا توجد خدمة عامة مهيأة؛ تُبقي النسخة واجهة الغرف غير مفعلة ما لم يضبط عنوان الخادم عند البناء. لا يعد نجاح الاختبارات المحلية إطلاقًا عامًا أو إكمالًا للمناهج.
