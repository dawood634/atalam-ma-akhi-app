# الغرف المتصلة: ما نُفذ وما لم يُفعّل

## التنفيذ

أضيف خادم WSGI يدعم SQLite محليًا وPostgreSQL خارجيًا، وعميل Flutter مع حفظ جلسة في التخزين الآمن، وواجهة منفصلة لغرفة الطالب وغرفة المعلم بحسب الصلاحية التي يمنحها الخادم. لا يغيّر الضغط على زر محلي صلاحية الجلسة المتصلة.

المعلم ينشئ فصلًا بدعوة إصدارها من مشرف المنصة، ويحصل على جلسة خاصة ورمز انضمام من ثمانية أحرف. الطالب ينضم بالرمز واسم مستعار؛ لا يطلب بريدًا أو هاتفًا أو اسمًا كاملًا. رمز الطالب لا يمنح صلاحية المعلم، والطالب لا يقرأ قائمة زملائه.

المعلم يعيّن درسًا من حزمة المجموعات الحالية، ويقرأ آخر نتيجة وأفضل نتيجة وعدد المحاولات لكل طالب. الخادم يصحح الإجابات بنفسه، ولا يقبل حقل درجة يرسله الجهاز. هذه نتائج تدريب في مسودات التطبيق، وليست امتحانات رسمية أو نظامًا محصنًا من الغش؛ إجابات التدريبات موجودة أيضًا في حزمة التعلم دون اتصال.

## عدم الاتصال وإعادة الإرسال

عند إكمال اختبار جديد في جلسة طالب مرتبطة، تحفظ النتيجة المحلية أولًا، ثم تضاف الإجابات إلى قائمة انتظار محلية بهوية طلب عشوائية ثابتة. تجرى المزامنة عند فتح الغرفة أو الضغط على التحديث، وليست خدمة خلفية مستمرة.

الطلب المعاد بالهوية نفسها والإجابات نفسها لا يزيد عدد المحاولات على الخادم. تأكيد طلب قديم لا يمحو نتيجة جديدة أضيفت أثناء الاتصال. تبقى البيانات المنتظرة إذا تعطل الخادم أو لم يؤكد الطلب. قائمة غير قابلة للقراءة لا تحذف بصمت. لا تُرفع نتائج قديمة لم تحفظ إجاباتها مع الربط.

## الجلسات والبيانات

- لا تحفظ دعوة إنشاء المعلم في جلسة الجهاز، ولا توضع في APK أو المستودع.
- تحفظ الجلسة عبر `flutter_secure_storage`؛ لا يوضع رمز المصادقة في SharedPreferences أو عنوان الطلب.
- تخزن قاعدة الخادم بصمة رمز المصادقة، لا الرمز الخام.
- عنوان الخادم مثبت عند البناء؛ يرفض العميل HTTP العام، وعناوين تتضمن اسم مستخدم أو استعلامًا أو مسارًا فرعيًا. HTTP المحلي مسموح فقط في اختبار صريح على loopback.
- لا يتبع عميل الشبكة التحويلات؛ لا ينقل ترويسة المصادقة إلى عنوان وجهة محوّلة.
- سجل الخادم لا ينبغي أن يتضمن أجسام الطلبات أو ترويسات المصادقة. تحفظ الاستجابات بتوجيه no-store.
- يوجد حد لعدد الطلبات وحجم الجسم وعدد الطلاب (٥٠ في الغرفة).
- تنتهي الغرفة بعد ٣٠ يومًا. تحذف الغرف المنتهية وطلابها ونتائجها عند معالجة طلب API تالٍ. يلزم جدولة تنظيف خارجية إذا كان المطلوب محوًا عند لحظة انتهاء المدة دون طلب لاحق.
- تغيير رمز الانضمام يمنع الانضمام بالرمز القديم، ولا يفصل الطلاب المرتبطين سابقًا.
- حذف طالب يزيل بياناته المتصلة؛ حذف الغرفة من المعلم يزيل طلابها ونتائجهم. واجهة الحذف تطلب تأكيدًا واضحًا. لا يحذف ذلك تقدم التدريبات المحلية.
- ملفات قاعدة البيانات والنسخ الاحتياطية تحتاج حماية وتشفيرًا على مستوى الاستضافة. لم تعتمد هذه البنية إنتاجيًا بعد.

## الاختبارات الفعلية

اختبارات الخادم تستخدم قاعدة حقيقية واتصال HTTP محليًا. تغطي فصل الغرف والصلاحيات، والتصحيح على الخادم، والتكرار المتزامن، وحد السعة، واستمرار البيانات بعد إعادة إنشاء الخدمة، وتغيير الرمز، والحذف المتسلسل وانتهاء المدة، والتحقق من المدخلات وحدود الطلبات.

اختبارات عميل Flutter تغطي حفظ الجلسة خارج التفضيلات العامة، وعدم حفظ دعوة المعلم، ورفض عنوان غير آمن أو انتقال جلسة إلى خادم مختلف، وبقاء النتائج بعد إعادة التشغيل، وثبات هوية إعادة الإرسال، وعدم محو نتائج جديدة أثناء المزامنة، واشتراط تأكيد الخادم، وإظهار أن الخدمة العامة غير مفعلة إذا لم يضبط عنوانها.

## التهيئة قبل النشر

ملفات الخادم: `server/app.py` و`server/Dockerfile` و`server/compose.yaml`. خادم Gunicorn هو نقطة تشغيل WSGI، وملف Compose يربط منفذ الخدمة بعنوان loopback فقط، مع مجلد بيانات دائم. يلزم إنهاء TLS موثوق وحماية الشبكة خارج الحاوية؛ لا يعد منفذ HTTP الداخلي خدمة عامة جاهزة.

إعدادات الاستضافة المطلوبة:

- `TEACHER_INVITE`: قيمة عشوائية خاصة، لا تقل عن ٣٢ حرفًا، لا ترسل إلى التطبيق مسبقًا. تمنح فقط لمن يسمح لهم بإنشاء فصول. التوزيع والاستعادة والإبطال الفردي لكل معلم لم يكتمل نظامها بعد.
- `CLASSROOM_DATA_DIR`: مجلد قاعدة البيانات الدائم، المملوك لمستخدم الخدمة.
- HTTPS واسم نطاق، ونسخ احتياطي وتشفير ومراقبة وحدود شبكة مضبوطة بحسب الوكيل الفعلي. لا نثق بترويسة X-Forwarded-For عشوائية.
- متغير بناء GitHub `CLASSROOM_API_URL` لأصل HTTPS بعد اختبار الخدمة. لا يحتوي كلمة مرور أو رمز جلسة. إذا كان فارغًا تبقى الواجهة غير مفعلة بوضوح.

لم تنشأ استضافة عامة أو حساب جديد أو التزام مالي، ولم تضبط قيمة حقيقية لدعوة المعلم. لم تختبر الروابط على هاتفين فعليين. لم يختبر بناء Docker وتشغيله على مزود استضافة فعلي. المساعد التوليدي لم يضف إلى الخادم بعد.

## فجوات تمنع الإطلاق العام

استعادة جلسة بعد فقد الجهاز أو حذف التطبيق، وإدارة حسابات المعلمين ودعواتهم الفردية، والإلغاء الفردي للجلسات، والتنظيف المجدول، والتحقق المستقل من الخصوصية والحماية، واختبار الضغط والنسخ الاحتياطي والاستعادة، وتجربة هاتفين، وإكمال المحتوى المعتمد. تبقى شروط النشر ذات الصلة غير مكتملة في سجل الجاهزية.

المراجع التقنية: https://pub.dev/packages/flutter_secure_storage/versions/10.3.4 و https://pypi.org/project/gunicorn/ . مجرد استخدام مكتبة تخزين آمن أو خادم معروف لا يشهد باجتياز التطبيق مراجعة أمنية مستقلة.

## المسار المجاني المعتمد بطلب المالك

طلب المالك عدم استخدام أي خدمة مدفوعة. استبدل المقترح السابق بخادم **Render Free** وقاعدة **Neon Free** خارجية. الملف `server/render.proposed.yaml` يحدد `plan: free` ولا ينشئ قرصًا مدفوعًا. يتطلب `DATABASE_URL`، ويرفض بدء الخدمة إذا غابت القاعدة الخارجية بدل حفظ بيانات الطلاب مؤقتًا داخل Render.

- Render المجاني يتوقف بعد ١٥ دقيقة من عدم الاستخدام؛ قد يحتاج أول طلب نحو دقيقة لإيقاظه. لا يستخدم هذا المقترح SQLite داخل Render، ولا قاعدة Render Postgres المجانية التي تنتهي بعد ٣٠ يومًا.
- Neon Free، وفق صفحة الأسعار المفحوصة في ١٦ نوفمبر ٢٠٢٦، يتيح ١ جيجابايت و١٠٠ CU-hour شهريًا لكل مشروع، دون اشتراط بطاقة ائتمان للتسجيل المجاني. تبقى هذه حصص بداية محدودة، وليست وعدًا باستيعاب جميع طلاب اليمن أو مجانية بلا حدود.
- فحص `/health` لا يفتح اتصال قاعدة بيانات، حتى لا تبقي فحوص تشغيل الخادم قاعدة Neon نشطة دون تعلم فعلي.
- الاتصال الخارجي PostgreSQL يحتاج TLS. تعطيل TLS محصور باختبار صريح على loopback، ولا يسمح به لخادم قاعدة خارجي.
- لا توجد ترقية مدفوعة مصرح بها. عند بلوغ حصة مجانية يجب التوقف أو تقليل الاستخدام ضمن شروط المزود، لا تفعيل خطة مدفوعة دون توجيه جديد من المالك.
- لم ينشأ حساب أو مشروع لدى Render أو Neon بعد، ولم تُضبط مفاتيح حقيقية. يلزم تسجيل دخول المالك والتحقق من ظهور Free قبل الإنشاء، ثم اختبار الاتصال والاستعادة والحدود قبل فتح الخدمة للطلاب.

المراجع: https://render.com/docs/free و https://neon.com/pricing . أسعار وحدود الخدمات قابلة للتغيير، وتراجع عند التهيئة الفعلية. هذا المقترح يخص الربط وقاعدة البيانات؛ لا يتضمن خدمة ذكاء توليدي مدفوعة.
