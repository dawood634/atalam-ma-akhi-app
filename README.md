# أتعلم مع أخي — نسخة 0.4.0 للمناهج

اختيار صنعاء أو عدن، ثم الصف من السابع الأساسي إلى الثالث الثانوي.

## حالة المحتوى الفعلية

- ١٣٦ عنوان كتاب مرشح في فهرس المصادر، وليست مناهج مكتملة أو معتمدة.
- فُحصت بيانات ثلاث عينات PDF. لم تعتمد مطابقة أحدث الطبعات رسميًا.
- مسودة وحدة رياضيات للسابع: عشرة دروس أصلية و٣٠ سؤالًا في المجموعات والعلاقات وفق ترتيب فهرس العينة القديمة.
- بحث ومفضلة وحفظ آخر نتيجة وأفضل نتيجة، مع تكليف درس ونسخ تقرير في مساحة معلم محلية.
- مختبر تفاعلي للتقاطع والاتحاد ونموذج المجموعة والعنصر.
- لا توجد مواد مدرسية كاملة معاد صياغتها حتى الآن، ولا مراجعة مستقلة من معلم.
- تبقى نسخة التأسيس ذات ٢٠٠ كلمة و١٢٨ نشاطًا في قسم مستقل.
- لا توجد خدمة ذكاء توليدي متصلة أو ربط بين أجهزة المعلم والطالب.

التفاصيل وسجل التنفيذ: [docs/YEMEN_PLATFORM.md](docs/YEMEN_PLATFORM.md).
البيانات: [content/source_ledger.json](content/source_ledger.json).
يُظهر التطبيق حالة المصادر بوضوح ولا يعد التصنيف في الفهرس اعتمادًا.

## البناء والاختبارات

Flutter 3.35.7 / Java 17. تنشئ GitHub Actions ملفات Android دون استبدال التطبيق،
وتشغّل التحليل والاختبارات ثم تنشر APK تجريبيًا.
المعرّف `com.dawood.curricula.atalam_ma_akhi` مستقل عن نسخ التأسيس السابقة، ويبدأ بسجل جديد.
يُنشئ مسار البناء مفتاحًا تجريبيًا مخزنًا في cache ويربط إعداد توقيع Gradle به صراحة؛
هذا ليس نظام توقيع إنتاجيًا ولا ضمانًا دائمًا لتوافق كل ترقية.

الاختبارات تغطي حفظ التقدم والفصل بين التأسيس والمنهج، وسلامة فهرس المصادر،
وإكمال الاختبار التفاعلي وحفظ نتيجته. لا تغني هذه الفحوص عن مراجعة المعلمين وتجربة أجهزة حقيقية.

## سياسة التسليم النهائي

طلب المالك تسليمًا نهائيًا واحدًا. أوقف النشر العام التلقائي للنسخ التجريبية؛ يستمر البناء الداخلي والاختبار. حالة التسليم والمعايير والفجوات موثقة في [docs/FINAL_READINESS.md](docs/FINAL_READINESS.md)، ولا تعد عناوين الفهرس أو المسودات تغطية للمناهج.

صُحح تصنيف المادة لجميع العناوين المرشحة؛ تلميح الفرع مأخوذ فقط من العنوان الصريح ولا يثبت التكليف الرسمي. يحتوي [content/coverage_audit.json](content/coverage_audit.json) على الحصر، و[content/release_readiness.json](content/release_readiness.json) على حالات النطاق والقبول.

## تنفيذ الغرف المتصلة

أضيف خادم وعميل للغرف، بتصحيح النتائج على الخادم وقائمة انتظار لإعادة الإرسال. الخدمة العامة غير مفعلة، وتظهر هذه الحالة صراحة في الواجهة. تفاصيل الاختبارات وما يلزم قبل النشر: [docs/CLASSROOM_SERVICE.md](docs/CLASSROOM_SERVICE.md). لم تضبط استضافة أو مفاتيح حقيقية، ولا تزال استعادة الحسابات واختبارات الأجهزة والمراجعة المستقلة غير مكتملة.
